# FPTI 四重人格测试

Fourfold Personality Type Indicator。24 道情境题，每题 4 个选项，约 5 分钟完成。页面沿用 [CBTI](https://github.com/SherW2012/CBTI/blob/main/index_v2.html) 的奶油白底、暖琥珀色、衬线字体、480px 单列布局、圆角卡片和逐题答题流程。

## 四种模式

| 编号 | 名称 | 关注点 |
| --- | --- | --- |
| 1 | 合作型 · 协调者 | 协作、关系、稳定交付 |
| 2 | 主导型 · 掌舵者 | 自主判断、表达、边界 |
| 3 | 回避型 · 守望者 | 风险、谨慎、防御 |
| 4 | 竞争型 · 竞逐者 | 比较、认可、争取优势 |

这里的“四重人格”是同一个人在不同情境下的四种反应模式，不是四个独立身份，也不是精神疾病概念。本测试为原创自我探索与娱乐工具，未经心理测量学验证，不用于心理诊断，不与 MBTI 类型建立对应。

## 运行与发布

仓库根目录的 `index.html` 是入口。用任意静态服务器打开根目录，例如 `python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

GitHub Pages：Settings → Pages → Deploy from a branch → main → / (root) → Save。启用并发布成功后，地址为 https://sherw2012.github.io/FPTI/ 。提交网页文件不会自动开启 Pages。

页面使用 CBTI 同版本的 React、ReactDOM、Babel CDN 和 Google Fonts，需要联网。字体不可用时退回系统衬线字体；脚本加载失败会显示刷新提示。答案只保留在当前页面内存中，不上传、不写入本地存储，刷新即清空。

## 题库与计分

- `questions.js`：24 道原创题、四种模式解释、六类情境、纯函数计分。
- `index.html`：首页、答题页、结果页；支持上一题修改、重新测试和键盘选择。
- 六类情境各 4 题：陌生社交、协作分歧、自我表达、机会选择、关系边界、失误反馈。题目交错排列，结果按情境汇总。
- 每题四个选项分别对应一种模式，选中得 1 分。每种模式在 A/B/C/D 各出现 6 次，不固定按字母归类。
- 总分始终为 24。得分占比 = 该模式得分 / 24，不是人口百分位、准确率或心理特质强度。
- 最高分同分时显示“并列主导”；所有模式均为 6 分时显示“四型均衡”。不使用固定排序强行裁决。
- 情境分析每类仅 4 题，只描述这次选择的分布，不把不同情境之间的差异解释为因果关系。

验证：`node verify.cjs` 检查题量、选项平衡、四型主导、并列、均衡、无效输入与情境汇总。
